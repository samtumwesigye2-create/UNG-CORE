# UNG Foundation Tranche 2

This stacked tranche adds six shared capabilities:

- device identity / fleet PKI registry and trust-state controls
- governed MLOps lifecycle with shadow, canary, production and rollback stages
- sensor startup/periodic self-test framework
- resource admission/priority scheduler for CPU/GPU/NPU/FPGA workloads
- canonical schema/data-contract registry
- bounded asynchronous internal event bus

Production certificate issuance/revocation, TPM/secure-element operations, remote exporters, and distributed message brokers remain platform adapters. The shared core models state and policy without pretending to perform unavailable hardware operations.
