# UNG Foundation Tranche 4

Group 3 of 3 completes the remaining shared roadmap gaps:

- dependency-aware benign mission/workflow orchestration
- metric-map/geofence/route utilities with explicit map-version provenance
- operator HMI state with prioritized alarms, roles and degraded-mode visibility
- API policy core for service identity, RBAC, request size and rate limits
- backup/disaster-recovery integrity, RPO/RTO metadata and restore-test evidence

External CRS conversion, tile/elevation providers, UI rendering, API gateway middleware, durable backup stores and key escrow remain explicit adapters or infrastructure integrations.
